# Shout Utility

A simple command-line utility to display text to standard output.

## Usage

```bash
shout [options] [string ...]
```

### Options:
- `-n`: Omit the trailing newline.

## Description
The `shout` utility writes any specified operands, separated by single blank (` `) characters and followed by a newline (`\n`) character, to the standard output.

If the `-n` option is specified, the trailing newline character is suppressed.
